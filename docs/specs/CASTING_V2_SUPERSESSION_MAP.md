## The two shapes this sweep found, named so the next one is faster

**Shape 1 — A DOCUMENT'S OWN NAMED LIMIT IS THE MOST DANGEROUS THING IN IT.**
`applySheetTaste`'s docblock does the right thing: it states a limit it cannot
fix, in detail, with a measurement (189 twins in 200 sheets). That paragraph is
exactly why nobody looked at the male case — **a stated limit reads as a
COMPLETE account of where the design is weak**, and its neighbour went unexamined
for months. A limit paragraph should say what it has NOT measured, not only what
it has.

**Shape 2 — A SCRIPT IS AN ARTIFACT THAT CARRIES A RULING.** The skin court's
header quotes its own dispatch order. Nothing in the repository says it was
folded; a seat opening that file next month reads a live order. **Design docs get
swept for supersession and scripts do not**, and a court runner's header is as
much a claim about the program's state as any page in `docs/`.

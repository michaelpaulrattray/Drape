# 08 — Assets & Library

## Assets
User-supplied source material (products, garments, logos, backdrops, audio). NOT generations.
- Search ("try 'blue bottle' or 'worn denim'") + smart-set chips with counts: All 48 / Products 21 / Garments 9 / Logos 4 / Backdrops 8 / Audio 6. Active chip = ink pill.
- Grid `auto-fill minmax(150px,1fr)`, gap 12: **Upload dashed tile first** ("Classified on arrival" — classification is automatic, no folder ceremony), then asset cards: 1:1 image slot, kind pill top-left, name 11px + mono usage count ("used 12×") below. No brand dots or colour coding on cards — media stays clean.
- Scope-filtered by project.

## Library
Everything generated, organised by time. Two lenses via a segmented control:
- **Kept** — downloads/exports/saved looks. Blurb: "Things you downloaded, exported, or saved as a look. Attempts stay where you made them."
- **All** — everything incl. attempts; "Unkept frames clear after 30 days."
- Search + kind filter chips (Images / Video / Try-on / UGC / Upscaled).
- **Dated groups**: TODAY / YESTERDAY / EARLIER THIS WEEK / EARLIER — mono eyebrow + hairline + count per group, then the standard media-card grid (4:5 slot, kind pill, name + mono time below). Neutral `--media` wells; never tinted placeholders.
- Counts in the header respond to scope ("1,842 frames · 1,530 clearing" / "84 kept in Acme Skincare").

# 09 — Settings & account

## Account menu (topbar avatar)
216px dropdown card: identity block (name + email), then Settings / Members & invites / Billing & credits (each deep-links into the settings modal tab), theme row, sign out. Click-away closes (capture-phase, `data-account-menu` marker).

## Settings modal (z-40)
Centered card 880×620 max, header (title + workspace name + ×), left tab rail + content pane, footer ("Changes save as you edit" + Cancel/Done).
Tabs: **Profile** (avatar, name, email, workspace), **Usage** (credit meter, per-model usage rows), **Billing** (plan card, payment, invoices), **Members** (member rows: gradient avatar tile, name/email, role select Owner/Admin/Creator/Reviewer, project scope; invite row), **Notifications** (toggle rows), **Security** (sessions, 2FA row).
All rows use the leader/hairline list grammar; no cards-in-cards.

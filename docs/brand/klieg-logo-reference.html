Rules
  • Always lowercase. No caps variant exists, for any context.
  • The bulb is the only warm element in the identity — everything around it stays severe, monochrome, editorial.
  • No color, ever. White on #0A0A0A; near-black on white.
  • Watermarks: corner-set, reduced opacity, glow dimmed or absent — the studio never joins the cast.
  • Motion: letters light left to right, bulb last and brightest. This is the only logo animation.
  • Final cut: license a grotesque (Söhne class) and re-tune dot metrics + glow to it; this file uses a system stand-in.
